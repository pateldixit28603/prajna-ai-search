## 1Password Security Incident — what is this about and why does it matter?

Unlike LastPass, which suffered multiple security incidents between 2011 and 2022 including a 2022 breach of user data, billing information, and vaults [2], 1Password has not been associated with a major publicized security incident in the provided search results. However, credential stuffing attacks remain a risk for any password manager when users reuse passwords across sites, as 81% of users reuse passwords across multiple sites [5]. The importance of 1Password's security model lies in its local encryption and vault design, which differs from cloud-based managers that have experienced breaches. Users should still follow best practices such as using unique passwords and enabling two-factor authentication where available.
